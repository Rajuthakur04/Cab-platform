# 🚖 Bihar Cabs - MERN Cab Booking & Fleet Platform

A modern, full-stack car rental and cab booking application tailored for Bihar and North India routes (Patna, Gaya, Muzaffarpur, Rajgir, Darbhanga, etc.).

---

## 🌟 Key Features

- **Fleet Showcase**: Authentic fleet cards featuring Innova Crysta, Scorpio-N, Ertiga, Aura, and Wagon-R.
- **Instant Booking Engine**: One-way, round-trip, airport transfers, and local rental booking forms.
- **Admin CRM Dashboard**:
  - Live revenue metrics & booking stats
  - Real-time driver fleet status & assignments
  - Printable **A4 Tax Invoices** with GST/SAC breakdown
  - Customer registration & booking logs
- **Mobile-First Experience**:
  - App-style mobile bottom navigation bar
  - Floating direct WhatsApp & Call contact widget
  - Responsive across all screen sizes
- **100% Free Cloud Architecture**:
  - **Database**: MongoDB Atlas M0 Free Tier
  - **Backend**: Render Free Web Service
  - **Frontend**: Netlify Free CDN Hosting

---

## 🛠️ Tech Stack

- **Frontend**: React 18, TypeScript, Vite, Lucide Icons, Custom CSS Design System
- **Backend**: Node.js, Express.js, Mongoose ODM, CORS, Dotenv
- **Database**: MongoDB Atlas Cloud

---

## 🚀 Local Development

### 1. Backend Setup
```bash
cd server
npm install
# Set MONGODB_URI in .env
node server.js
```

### 2. Frontend Setup
```bash
npm install
npm run dev
```
